[ 01 / AZURE AI ]

Azure AI Document Intelligence

Document extraction operates within isolated Azure Cognitive Service containers. Customer PDFs, invoices, and physical waybill photos are never retained for third-party public foundation model training.

[ 02 / KUBERNETES ]

Azure Kubernetes Service (AKS)

Core 3-way matching logic runs in hardened AKS clusters deployed in the West Europe cloud region, with microsecond multi-tenant isolation, automatic horizontal pod autoscaling, and zero shared database storage.

[ 03 / IDENTITY ]

Microsoft Entra ID & RBAC

Granular role-based access control (Store Gate Receiver, AP Clerk, Procurement Manager, CFO). Seamless Single Sign-On (SSO) integration with SAML 2.0, Okta, and Microsoft Entra ID.

[ 04 / ENCRYPTION ]

AES-256 & TLS 1.3 Standards

All documents at rest in Azure Blob Storage are encrypted using AES-256 with customer-managed keys (CMK) in Azure Key Vault. All transmission uses TLS 1.3 with strict HTTP Strict Transport Security (HSTS).
